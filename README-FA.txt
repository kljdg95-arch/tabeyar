تابع‌یار — نسخه PWA

فایل‌های این پوشه را در ریشه یک مخزن GitHub قرار بده؛ فایل index.html باید در ریشه باشد.

انتشار رایگان:
1) در GitHub یک مخزن جداگانه به نام tabeyar بساز.
2) فایل‌های این پوشه را در ریشه مخزن آپلود کن.
3) وارد Settings > Pages شو.
4) در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کن.
5) Branch را روی main و پوشه را روی /(root) بگذار و Save کن.
6) پس از انتشار، آدرس GitHub Pages را با HTTPS باز کن.

نصب:
- اندروید: Chrome > باز کردن سایت > نصب برنامه یا منوی سه‌نقطه > نصب برنامه/افزودن به صفحه اصلی
- iPhone/iPad: Safari > Share > Add to Home Screen
- Windows: Chrome یا Edge > دکمه Install در نوار نشانی یا منوی مرورگر

برای نصب و استفاده آفلاین، بار اول سایت باید با اینترنت باز شود.
